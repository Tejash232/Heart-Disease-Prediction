# Heart Disease Prediction Using Machine Learning
## Live Demo

🚀 [Click here to try Heart Disease Prediction](https://heart-disease-prediction-ujhj.onrender.com)

## About the Project

This project uses Machine Learning to predict the likelihood of heart disease based on patient medical attributes.

A Logistic Regression model is trained using the Heart Disease dataset and integrated into a web application built with Streamlit.

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Streamlit
- Google Colab

## Machine Learning Workflow

1. Data collection
2. Data preprocessing
3. Exploratory Data Analysis
4. Train-test split (80:20)
5. Logistic Regression model training
6. Model evaluation
7. Prediction on new input data

## Model Performance

- Training Accuracy: 85.12%
- Testing Accuracy: 81.97%
- Algorithm: Logistic Regression

## Features

- Interactive patient input form
- Prediction using a trained ML model
- Streamlit web interface
- Real-time model inference

## How to Run Locally

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Heart-Disease-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
